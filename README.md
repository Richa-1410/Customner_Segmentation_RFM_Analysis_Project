# Customer Segmentation using RFM Analysis (Retail & E-Commerce)

## Problem Statement
Retail businesses lose revenue when they send generic marketing campaigns to all customers. This project segments online retail customers based on **Recency (R)**, **Frequency (F)**, and **Monetary (M)** behavior using Python, Oracle SQL, and Power BI to drive targeted retention strategies.

## Key KPIs
- **Total Revenue & Active Customers**
- **Average Order Value (AOV)**
- **Segment-wise Customer Count & Revenue Share (%)**
- **Recency (Days since last purchase), Frequency (Total Invoices), Monetary (Total Spend)**

## Tech Stack
- **Python (Google Colab):** Pandas, NumPy (Data cleaning, EDA, RFM scoring)
- **Oracle SQL:** DDL, `NTILE(5)` window functions, analytical views
- **Power BI:** Interactive dashboard with slicers and drill-down
